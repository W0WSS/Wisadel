# 维什戴尔的爆破委托（原型）

参考 `MonsterDeleter` 的桌面演出思路重写的 Windows / PyQt6 小工具：先召唤维什戴尔，随后直接在桌面上单击真实文件图标。程序识别桌面选中项后立即锁定并播放投弹、爆炸动画和头部表情特写，在炸弹命中时将目标移入系统回收站。

当前演出还原了视频中的夸张表情变化：炸弹命中后先播放白闪、火球、冲击波、火星与烟尘，再从 8 种原版风格表情中随机选择一个头部特写，快速放大、抖动后缩回。

## 安全设计

- 鼠标坐标只用于找到 Windows 桌面图标；真实删除路径由 UI Automation 图标名称与系统桌面目录共同解析，无法唯一对应时不会执行。
- 仅识别桌面上的真实文件，不处理文件夹、“此电脑”或“回收站”等系统图标。
- 单击目标后立即进入攻击流程，不再弹出文件选择器或二次确认窗口。
- 锁定时记录文件指纹；如果炸弹命中前文件被替换或修改，会中止操作。
- 使用 `send2trash` 移入回收站，不做不可逆永久粉碎。
- 禁止把当前脚本/可执行文件自身和磁盘根目录设为目标。
- 任意演出阶段均可按 `Esc` 退出；从终端运行时也可按 `Ctrl+C`。

## 源码运行

需要 Windows 10/11 与 Python 3.10+：

```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

程序不会接受启动参数自动选中或删除文件。召唤完成后，程序窗口会进入鼠标穿透状态；直接单击桌面上的目标文件图标即可立即开始投弹。单击空白处、文件夹或系统图标不会执行删除，等待阶段可按 `Esc` 退出。

程序会合并 Windows 当前全部显示器的虚拟桌面区域，并分别使用原生坐标读取图标、使用 Qt 的 DPI 感知坐标定位特效，可兼容副屏位于主屏左侧（负坐标）和不同缩放比例。显示器插拔或分辨率变化时会自动重新同步覆盖区域。

直接运行 `py main.py` 时不会隐藏终端，方便查看错误和使用 `Ctrl+C`；只有通过已安装的右键菜单启动时才会隐藏控制台窗口。

## 右键菜单

安装当前用户的文件右键菜单，无需管理员权限：

```powershell
py main.py --install-menu
```

源码模式会使用 `pythonw.exe` 启动，打包版本使用无控制台窗口模式，因此右键召唤不会显示终端。右键菜单只负责召唤角色，不会把被右击的文件自动设为目标；角色出现后再单击桌面目标。

如果之前安装过旧版右键菜单，更新代码或 EXE 后必须重新运行一次：

```powershell
py main.py --install-menu
```

卸载：

```powershell
py main.py --uninstall-menu
```

Windows 11 的经典菜单项可能显示在“显示更多选项”中。

## 打包

双击 `build.bat`，或在项目目录运行它。输出位于 `dist\WisadelDeleter.exe`。打包完成后可执行：

```powershell
dist\WisadelDeleter.exe --install-menu
```
